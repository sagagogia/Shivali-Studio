# Local source-image preview

The studio calls the audited OpenMontage `video_stitch` local tool, revision `195eab24478dc9363326aec437aefc3701635ddf`. This is a **still-based source-image preview**, not generated fashion-model motion. Images appear in order as static, aspect-preserving holds with slate padding and hard cuts. There is no narration. Sound is silent by default; an optional manually approved soundtrack requires an explicit operator rights declaration. Production approval remains a separate studio gate.

`renderPreview` in `src/studio/render.ts` receives server-selected approved image descriptors and their approval hashes. The caller must enforce current concept/asset approval; the adapter cannot establish business approval from a filesystem path. Never populate paths, output directories, or OpenMontage root from request JSON. The server supplies these from private asset storage and configuration.

The adapter validates campaign/version, 1–12 PNG/JPEG/WebP images, 25 MB per image, absolute canonical paths, signatures and SHA-256. The worker rechecks hashes, copies into fixed filenames, verifies snapshot hashes and rejects images above 40 megapixels. It allocates exactly 810 frames across the sources (27 seconds at 30 fps). For one source, two identical holds satisfy OpenMontage's minimum two clips. FFmpeg creates local H.264 clips at 1080×1920; the registry registers only the audited `video_stitch` module and executes its `stitch` operation. A local stream-copy remux adds faststart metadata. FFprobe verifies resolution, pixel format, codec, frame rate and duration; FFmpeg decodes the complete output with errors fatal.

Every run has a fresh private `preview-*` directory under the server-supplied output directory. `packet.json` records the approved inputs and target. `asset-manifest.json` records frame allocation, input hashes and the actual OpenMontage result. `render-report.json` records verification, output hash, tool revision and zero cost. `preview.mp4` is released only after verification. Failure removes partial media and work files and persists the input packet, failed report and `failure.json`. These artifacts contain local paths and campaign metadata; keep them private. They contain no credentials or environment dumps.

Configure `SHIVALI_OPENMONTAGE_ROOT` on the server if the checkout moves. Default: `/workspace/scratch/openmontage-inspection-_5ol60ly/OpenMontage`. Its `.venv/bin/python`, Git revision, FFmpeg and FFprobe must be available. No dependency install, provider discovery, model selection, credentials, download or paid call occurs. An incompatible checkout fails closed.

The worker gets a minimal environment with no inherited API secrets. It uses `spawn` with argument arrays, never a shell, and is killed with its process group after 180 seconds. Individual worker subprocesses have a 120-second timeout. A network namespace is used when `unshare -n` is permitted. This workspace denies that operation; the fallback disables Python network connections and restricts code to local tool/FFmpeg paths. The fallback is defense in depth, **not OS-level network isolation**. The report records namespace availability. For a hard network boundary run the whole studio in a container with networking disabled. This integration trusts the installed, pinned OpenMontage checkout and system binaries; it does not sandbox malicious changes to them.

Verification:

```sh
node --experimental-strip-types --test tests/render.test.ts
```

The test renders and fully decodes a real 27-second silent fixture preview and a second preview with synthetic licensed-test audio, verifies original-image preservation and artifacts, rejects invalid bounds, relative/symlink paths and changed hashes, and checks unavailable-worker cleanup. It uses a synthetic FFmpeg fixture and makes no external calls.

Optional soundtrack input is `music?: { id: string; path: string; sha256: string; licenseConfirmed: boolean }`. The server selects a manually approved music asset and requires `licenseConfirmed: true`; this records the operator declaration and does not infer legal rights. Only canonical local MP3/WAV files up to 25 MB are accepted, with signature, hash and FFprobe checks. The worker snapshots and rehashes the file, loops short tracks to 27 seconds, halves level, limits peaks, fades in over 0.5 seconds and out over 1.5 seconds, then muxes AAC stereo at 48 kHz with the actual OpenMontage montage. FFprobe verifies audio format, full decode covers both streams, and FFmpeg measures final audio: peak must remain below -0.1 dBFS and mean above -60 dBFS. Silent or clipping soundtracks fail instead of silently disappearing. `report.audio` records source ID/hash, operator declaration, processing and measured levels; no-music runs record `mode: "silent"`. This technical check cannot judge musical quality or rights.
