# Shivali AI Marketing Studio — internal first release

Authorized scope: user requested the full internal marketing agency with installed OpenMontage, OpenHiggsfield, Hallmark and agents, and authorized modification. Work is local-only in /workspace/shivali-marketing-studio, branch shivali/studio. Original checkouts remain intact. No paid calls, automatic publication, external credential provisioning or deployment.

Use the OpenHiggsfield Next.js 16 / React 19 codebase as the app foundation and preserve its original generator under /generate, disabled unless explicitly configured. Adopt Hallmark Atelier's restrained warm paper / cool slate palette for a task-first app. System fonts avoid network dependencies. Use durable node:sqlite database and private local assets, not browser-local production history or public cloud uploads. Default bind localhost.

Primary flow: intake one or many garments; persistent campaigns; create an explicitly rule-based offline creative brief (never mislabel it live LLM inference), cinematic shot plan totaling 27 seconds, draft captions/hooks/hashtags; attach source-backed trend research; approve the exact concept version; upload or generate model images with configured fal provider only after a per-call budget/approval check; record manual garment QA with automated technical checks; approve assets; render an explicitly labelled source-image preview through OpenMontage's local tools; review final preview and export video/copy/history. Publication remains an export-only human handoff. Never imply a still-based preview is generated fashion-model motion.

Seed MF03162, silk, metallic blue, necklace and dupatta included. The chat photographs are not accessible as local files, so do not invent image assets; user can upload through the app. Do not fabricate trend findings, costs, approvals, licenses or metrics. Costs are integer USD cents; reserve before remote work and reconcile after. Max default experiment budget $5. Exact garment fidelity requires human product review and cannot be guaranteed by a model.

Entities and API types are in src/studio/types.ts. SQLite transactions and versioned approvals must protect against stale or duplicate actions. Canonical artifact hashes and append-only events bind review history to assets. Replacing an asset or revising a plan invalidates downstream approval. No rendering until concept and all selected assets have been approved; final-render approval precedes export. Uploads: jpg/png/webp/mp4/wav/mp3 only, check magic bytes, cap 25 MB, UUID filenames outside public directory, reject traversal. Mutating API requests require same-origin or absent Origin for local CLI. No arbitrary shell execution or user-provided paths. Server routes never expose secret values. Existing Vercel upload route must be disabled by default.

Paid generation and image-to-video integrations remain clearly blocked until credentials, commercial terms, source images, and explicit per-job approval exist. Implement safe configuration reporting and exportable generation request packets. Do not use OpenAI API code in this release; fal is the previously selected provider. Future unattended reasoning is an extension, not claimed complete.
