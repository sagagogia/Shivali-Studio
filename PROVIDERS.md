# Image generation provider

This release uses fal Nano Banana Pro edit (`fal-ai/nano-banana-pro/edit`) exclusively. No OpenAI provider is used. The server submits one 2K, 9:16 image with garment photographs encoded as data URIs. There is no public upload step. References still leave the computer for processing by fal and its upstream model provider; review their current commercial terms and source-image permissions before enabling.

Paid generation is disabled unless both `FAL_KEY` and `SHIVALI_ENABLE_PAID_GENERATION=true` are present in the server environment. Never put the key in a `NEXT_PUBLIC_` variable. `getProviderStatus()` reports booleans and model/estimate details without exposing credentials. Each invocation also requires explicit approval and a reservation of at least 15 integer USD cents within the $5 campaign cap. The application must enforce the exact campaign-version approval and reserve/reconcile its durable budget before calling the bridge; the bridge does not replace those transaction gates.

The 15-cent estimate is the last inspected price for one 2K image, not an enforceable billing quote or spending limit at fal. Verify current pricing before enabling. Provider billing is authoritative. A timeout or transport failure after submission may still incur charges. The bridge never retries a submission automatically. `ProviderError.submitted` is conservatively true as soon as submission starts; `providerRequestId` is included when safely available. Keep the reservation on these uncertain failures. Check the provider dashboard before manually retrying; reconcile uncertain charges conservatively against the campaign reservation.

Queue polling is bounded to 60 checks and a two-minute overall abort deadline. No provider-supplied queue URL is trusted. Status and result paths use the base model ID without the `/edit` subpath, following the fal Queue API documentation (https://docs.fal.ai/model-apis/model-endpoints/queue). Image downloads require HTTPS on `fal.media` or its subdomains, no credentials or custom ports, and rejected redirects. Downloads and combined reference input are capped at 25 MB; PNG/JPEG/WebP signatures are checked. At most 14 references are accepted. Final files are created atomically without replacing existing output, with private file permissions. Output paths must be generated by trusted server code, never supplied by a request body.

A successful generation remains an unapproved asset. Inspect the actual image against the garment photographs for embroidery, fabric, metallic color, neckline, sleeves, hem, necklace and dupatta. Exact garment fidelity cannot be guaranteed. Manual product QA and asset approval are required before rendering or export.

Read-only schema checked 2026-11-02: https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/nano-banana-pro/edit . Transport tests use mocked responses; no paid generation was run during implementation. Run `node --experimental-strip-types --test tests/provider.test.ts`.
